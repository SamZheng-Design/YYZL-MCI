## RBF 计算模型

```
回收上限 = 融资总额 x 回收倍数
月回款 = 预估月收入 x 分成比例
预估回收期 = 融资总额 / 月回款
```

每份投资的回款按投资占比分配。

## 技术栈

- **框架**: Hono + TypeScript + JSX (SSR)
- **部署**: Cloudflare Pages (wrangler)
- **样式**: Tailwind CSS (CDN) + 自定义 CSS
- **图标**: FontAwesome 6.4 (CDN)
- **字体**: Inter + Montserrat + Noto Sans SC
- **交互**: 原生 JavaScript (inline script)
- **数据**: localStorage (客户端) + Mock 数据 (服务端)

## 项目结构

```
src/
├── index.tsx      # Hono 入口 + 路由 + 所有页面 + 交互
├── renderer.tsx   # JSX 渲染器 (HTML + CDN + 全局样式)
└── data.ts        # Mock 数据 + RBF 计算 + 统计函数
```
